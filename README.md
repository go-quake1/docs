# go-quake1 docs

Documentation site for the [go-quake1](https://github.com/go-quake1) organization — built with
MkDocs Material, versioned with [mike](https://github.com/jimporter/mike), served
at <https://go-quake1.github.io/docs/>.

```sh
pip install -r requirements.txt
mkdocs serve
```
